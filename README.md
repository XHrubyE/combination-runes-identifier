# Combination Runes Identifier
Plugin that helps identify the base elements of combination runes at a glance.

![img.png](img.png)


![img_1.png](img_1.png)
# Features
* Displays base element letters on combination runes (e.g. A + F for Smoke runes).
* Option to enable or disable colored letters/symbols.
* Option to enable or disable the overlay for inventory items.
* Option to disable the entire overlay
